# Ethos

The structuring rules, each with its reason and its enforcement form. **Mechanical** rules are enforced by `checks/` (ruff, import-linter, greps) — never spend review attention on them. **Judgement** rules are what the judgement scan and the reviewer look for.

Two tiers: **core** applies to any Python; the **FastAPI profile** applies when `detect.sh` reports `fastapi: yes`.

## Core (any Python)

| Rule | Why | Form |
|---|---|---|
| Imports at module top. One lazy import is tolerated only for a heavy native dependency used on one path (e.g. `weasyprint`), with a one-line comment. | Lazy imports hide dependencies and cycles; cycles are fixed by restructuring, not by hiding. | mechanical: ruff `PLC0415` |
| No unused imports or variables. | Noise; hides dead code. | mechanical: ruff `F401`, `F841` |
| **No `if TYPE_CHECKING:` blocks** except in `models/` for a genuine ORM relationship cycle (`Mapped["Other"]` both ways). A type-only import is a plain import; `from __future__ import annotations` already defers evaluation. A `TYPE_CHECKING` import that exists to dodge a layering rule (schemas → models) is a layering violation wearing a hat — fix the dependency (`model_validate(..., from_attributes=True)`, `Any`, or a Protocol). | Four extra lines per module for nothing; hides real cycles. | mechanical: `greps.sh` `TYPE_CHECKING_BLOCK` (models/ exempt); ruff `TC001-003` deliberately NOT selected |
| Line length 120, ruff-formatted. skip-magic-trailing-comma = true | Legibility; one formatter decision for everyone. | mechanical: ruff `E501` + `format --check` |
| Type classes are pydantic models in a `schemas/` package; internal value types extend a `StrictModel` base (`extra="forbid"`, `frozen=True`). Dataclasses are allowed only in an explicitly exempt subtree (e.g. an engine's config models holding callables). | Runtime validation at construction; one place to look for every shape. | mechanical: ruff `TID251` bans `dataclasses.dataclass`; judgement: which subtree is exempt, which models stay lax (LLM output) |
| External services are **client classes** in a `clients/` package: constructor takes `url`, `api_key`, `timeout`, `transport` (for tests), `retry` policy; one method per operation the caller performs; `from_settings(settings)` classmethod. No module-global transport seams. | Injectable, testable, one home per upstream. | mechanical: `greps.sh` flags module-level `_transport`; judgement: shape |
| Retry and bounded fan-out are utilities (`utils/retry.py::retry_async`, `utils/concurrency.py::bounded_gather`), not inline loops or nested `async def` closures with `nonlocal`. | Closures mutating shared state under `asyncio.gather` are the classic race; a utility is tested once. | mechanical: `greps.sh` flags nested `async def` + `nonlocal`; judgement: extraction |
| Prompts are `.md` files loaded through one `load_prompt(name)` in the prompts package (`functools.cache`, `FileNotFoundError` naming the path). No `Path(__file__)…read_text()` outside that module. | One way to find every prompt; instruction strings are prompts too. | mechanical: `greps.sh` |
| No leading-underscore helper sprawl in orchestration modules: a helper worth writing is worth a public name and a test. Dunders excepted. | Private names signal "don't test me"; in AI-written code they accumulate into untestable blobs. | mechanical: `greps.sh` counts `def _` per module (threshold in script); judgement: which to make public vs inline |
| Repeated `self.x = x` constructors become `@dataclass` (behaviour objects) — never pydantic for objects holding sessions/handles. | Boilerplate; `field(default_factory=...)` for per-instance defaults. | judgement |
| Dead code is deleted with importer evidence (`grep -rn "module.name"` across src and tests shows no runtime caller). "Schedule for removal" means list the uncertain set for the user, delete the certain set. | A deleted file can't rot. | judgement (evidence required) |
| Error paths are classified: **deterministic misconfiguration** (bad URL, illegal header, auth/credit statuses, 3xx/405) is **fatal** and propagates; **transient** failures (429/5xx after retry, network errors, malformed responses) may degrade per item. A `except Exception` that turns both into the same fallback is a defect. | The silent-failure that costs money: a bad key degrading every item to "new record" instead of failing the run. | judgement; hunter verifies |
| Behaviour parity is the default contract. Any change a user could notice (URL, status code, response body, fallback policy) is listed as a **decision for the user**, never slipped in. | The user owns product behaviour. | judgement |
| **Accept collaborators, never construct them.** A function or class takes its client/repo/matcher as a parameter; the only place `SomeClient(...)`/`from_settings(...)` is called is a **provider** (`dependencies.py` for FastAPI `Depends`, an explicit `build_*` factory elsewhere). The test seam is the parameter, not `monkeypatch`. | `new StripeGateway()` inside `processOrder` is untestable; injection makes the fake a one-line argument. | mechanical: `greps.sh` `CONSTRUCTED_IN_PLACE`; judgement: provider shape |
| **Closed sets are `StrEnum`s, constants are `Final`, both live in `constants/`** (or `constants.py` + `enums.py`). `Literal[...]` aliases for pydantic are derived from the enum, never retyped. Business code compares against the enum member, never a string literal. | `"completed"` typed in four files is four places to misspell it; an enum is one place and `match` gets exhaustiveness. | mechanical: ruff `PLR2004` (strings included), `greps.sh` `LITERAL_SET_COMPARE`; judgement: which sets are closed |
| **`require(value, what)`** collapses `x = await repo.get(...); if not x: raise NotFoundError(...)` into one line: `def require[T](value: T \| None, what: str) -> T` in `exceptions.py`, raising `NotFoundError(f"{what} not found")`. Variants only when a different status is correct (`require_owned` → 403). | The `orElseThrow` of the codebase; 40 copies of a three-line guard become 40 one-liners with uniform messages. | judgement; recipe 11 |
| **Functional by default:** pure functions taking immutable `StrictModel`s and returning new values; a class exists only to hold state or a handle (a client, a session). A class whose only state is one injected collaborator is a namespace — make it functions taking that collaborator. Never mutate a parameter; fold results after the gather. Comprehensions and `functools.partial` over accumulator loops; early return over nesting; `match` on an enum for dispatch. | Fewer moving parts to test; the type checker proves more. | mechanical: ruff `RET`, `PERF401/402`, `SIM`; judgement: class → functions, mutation |
| **Conciseness ceilings:** complexity ≤ 10, args ≤ 6, branches ≤ 10, statements ≤ 40, returns ≤ 6. Over the ceiling means a missing value object (bundle the args in a `StrictModel`), a missing function, or a dispatch table. Booleans are keyword-only (`FBT`). | AI output grows by appending; ceilings are the only thing that force it to split. | mechanical: ruff `C901`, `PLR0911/0912/0913/0915`, `FBT` |
| **Few docstrings, fewer comments.** The name carries the meaning. A one-line docstring only where the name cannot: an invariant, a unit, a non-obvious failure mode. A comment says *why*, never *what*. Commented-out code is deleted. No module docstrings that restate the filename; no `print`. | Docstrings that paraphrase the signature are sediment; the reader has the signature. | mechanical: ruff `ERA001`, `T20`; judgement: delete paraphrasing docstrings during the pass (no `D` ruleset — that enforces *more*) |
| **Deep modules, tight seams.** Public surface per module ≤ ~7 names, `__all__` on packages. A `Protocol` with one implementation is a hypothetical seam — delete it until a second adapter exists. **Deletion test:** if removing a module makes complexity vanish, it was a pass-through; if it reappears across callers, it earned its keep. Repos expose domain verbs (`get_open_claims`), not query builders. | Depth = behaviour per unit of interface learned; shallow modules cost the reader without paying back. | judgement (vocabulary: `mattpocock-skills:codebase-design`) |
| **Scalar constraints are `Annotated` aliases** (`Confidence = Annotated[float, Field(ge=0, le=1)]`) in `schemas/common.py`, reused by every model that carries the value. | One place for the rule; the field name reads as a type. | judgement |

## FastAPI profile

| Rule | Why | Form |
|---|---|---|
| Layering `routers → services → repos → models`; routers never import repos or `sqlalchemy`. | Controllers take a request, validate, call one service, return a DTO. | mechanical: import-linter contract generated by `check.sh` |
| `HTTPException` is imported by exactly one module (the global error handlers). Services raise domain errors from `exceptions.py` (`AppError` + 400/401/403/404/409/422/502 subclasses with `status_code` and optional `headers` class attrs). | Services don't know HTTP; one place maps status codes. | mechanical: ruff `TID251` bans `fastapi.HTTPException`; `greps.sh` names the one allowed importer |
| Repos raise nothing new: SQLAlchemy errors propagate raw and are mapped globally — `IntegrityError` by SQLSTATE (23505/23503 → 409, else 400), `DataError` → 400, `NoResultFound` → 404, `OperationalError`/`InterfaceError`/`TimeoutError` → 503, upstream `httpx.HTTPStatusError` → 502, `Exception` → 500 with the literal detail `Internal server error`. Detail is the first line of `str(exc.orig)`, never `str(exc)` (which carries the SQL and params); an empty message falls back to the exception class name. `get_db()` rolls back on exception. | FastAPI-native `{"detail": ...}` bodies; nothing leaks the query; a DB outage is a 503, not an opaque 500. | judgement + `tests/unit/test_error_handlers.py`-style table test (see recipes) |
| Routers return DTOs, never dicts; `response_model` on every endpoint; validation by typed params/`Literal`/pydantic bodies. **Mapping lives in `schemas/`, both directions:** ORM/domain → response via `from_*` classmethod on the response DTO; request DTO → domain via `to_*` on the request model. Services take and return schemas, never dicts. A `from_*` that only copies same-named fields is shallow — use `model_validate(obj, from_attributes=True)` instead. | Thin controllers; the mapping is testable without an app; no dict leaks through a layer. | mechanical: `greps.sh` flags `return {` and `db.commit` in routers; judgement: `from_*`/`to_*` placement |
| Business logic lives in services; a router makes one service call. Two calls in a router = a missing service function. Services are **injected** via `Depends(provider)` from `dependencies.py`; `app.dependency_overrides` is the test seam. | | judgement; `greps.sh` `CONSTRUCTED_IN_PLACE` |
| **Transaction ownership:** the use-case service function commits exactly once at its end; repos `flush`, never `commit`; routers never touch the session. | One owner per transaction; a repo that commits cannot be composed. | mechanical: `greps.sh` `COMMIT_OUTSIDE_SERVICE` |
| API version comes from config: `settings.api_version` → `settings.api_prefix` (`/api/v1`); routers declare domain-relative prefixes and are mounted under one versioned `APIRouter`; `/health` stays unversioned; old paths 404 (pinned by a test). | One-line version bump; no hard-coded `/api/`. | mechanical: `greps.sh` flags `prefix="/api/` in routers; judgement: the mount |
| DB models are SQLAlchemy 2.0 style: `DeclarativeBase`, `Mapped[...] = mapped_column(...)`, `__tablename__` on every model. | | mechanical: `greps.sh` |

## What this ethos is not

- Not `strict=True` globally on pydantic: LLM-output schemas keep `extra="ignore"` and lax coercion on purpose.
- Not a ban on `Any`: an ORM row inside an internal value type is `Any` so `schemas/` never imports `models/`.
- Not a rewrite: the live pipeline's observable behaviour stays identical unless the user decides otherwise.
- Not a docstring drive: the pass removes paraphrasing docstrings and `what` comments; it never adds them to meet a count.
- Not a Spring port: the vocabulary stays Python (`routers`, `services`, `repos`, `schemas`, `dependencies.py`), only the discipline (thin controllers, injected collaborators, mapping above the controller, one transaction owner) carries over.
